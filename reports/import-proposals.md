# Proposal logs import report

Generated by `scripts/import/proposals.py` from `proposals.xlsx` (sha256 `3948f46a3fd6…`). Each finding is dated by its row's Date Edited if that's a specific date, otherwise as_of = 2026-10-15 (D34). Each table has its own log, and its baseline is in `changesets/<resource>/0000/`. Changeset ids start from `--created-at 2026-11-03T16:00:00Z`: re-run this export with the same time to get the same ids. This run is from the frozen export: the sheets froze on 2026-11-02 (D63).

A changeset holds one system from one tab. Its changes hold no sheet references or summaries, and their reasons are the sheet's rationale text with only spaces and tabs tidied, or empty if the rationale is blank (D24, D26, D27, D29, D30). To find the changeset for a sheet row, or the rows behind a changeset, see [`import-proposals-changesets.csv`](import-proposals-changesets.csv).

Rows are attributed to a system only by these rules: New system = Yes is a new system; a place with one system of the type is that system; a place with several uses the system name (Payments: Notes; DX: the system-name column) and then the exact Country / Region; rows after a "Break for …" marker are a new system. Anything else is listed below, not guessed.

Tabs without a New system column: Data Exchange_NewVar_Log. In these, new systems are only found from break markers and the known cases.
